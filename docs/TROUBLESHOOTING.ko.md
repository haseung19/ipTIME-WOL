# 문제 해결

## 프로그램이 실행되지 않습니다

- Windows 10/11 x64 환경인지 확인하십시오.
- Windows PowerShell 5.1이 설치되어 있고 조직 정책이 실행을 차단하지 않는지 확인하십시오.
- 파일을 신뢰할 수 있는 배포처에서 받았는지 확인하고 [SHA-256](../bin/SHA256SUMS.txt)을 비교하십시오.
- 미서명 파일에 대한 SmartScreen 안내가 나타날 수 있습니다. 보안 설정의 무조건적인 해제를 권장하지 않습니다.

## 접속이나 로그인이 실패합니다

- 주소에는 `http://` 같은 접두사 없이 호스트/IP만 입력해도 됩니다. 다만 포트는 별도 입력하십시오.
- HTTP/HTTPS 선택이 공유기 설정과 일치하는지 확인하십시오.
- 공유기 관리자 화면이 **해당 주소/포트에서 실제로 열리는지** 확인하십시오.
- 외부망 접속이라면 원격 관리 기능, DDNS, 방화벽 및 라우터가 사용하는 WAN IP 환경을 확인하십시오.
- HTTPS를 사용한다면 인증서 오류나 호스트 이름 불일치 여부를 확인하십시오. 이 프로그램은 인증서 검증을 우회하지 않습니다.
- 관리자 ID/암호와 로그인 시도 제한을 확인하십시오.

## 로그인은 되지만 목록이 비어 있습니다

- 공유기 관리자 화면에서 WOL 대상 PC가 등록되어 있는지 확인하십시오.
- 공유기 펌웨어에서 동일한 API가 반환되는지 확인이 필요할 수 있습니다.

## WOL 요청 성공으로 나오지만 PC가 켜지지 않습니다

이는 **공유기가 명령을 정상 처리했다는 뜻**이지, PC가 부팅되었다는 증거는 아닙니다.

- 공유기 관리 화면의 WOL 버튼으로도 같은 현상이 발생하는지 먼저 확인하십시오.
- 대상 PC BIOS/UEFI의 Wake-on-LAN 또는 PCIe 웨이크 옵션을 확인하십시오.
- OS/랜카드의 WOL 기능, 전원 관리, 전원 꺼짐 상태에서 NIC 전원 공급, 유선 연결 등을 확인하십시오.
- 공유기에 등록된 MAC 주소가 실제 대상 유선 랜카드와 일치하는지 확인하십시오.

## 원클릭 아이콘이 작동하지 않습니다

- 처음에 선택한 PC가 공유기 WOL 목록에 계속 등록되어 있는지 확인하십시오.
- `ipTIME-WOL.exe`가 바로가기 생성 당시 경로에 그대로 있는지 확인하십시오. 이동했다면 프로그램에서 원클릭 바로가기를 다시 생성하십시오.
- 같은 Windows 사용자 계정에서 실행하고 있는지 확인하십시오. 저장 암호는 Windows 사용자 계정에 연결됩니다.
- 라우터 주소나 관리자 비밀번호가 바뀌었다면 GUI에서 다시 로그인하고 바로가기를 새로 생성하십시오.

## 설정 초기화

앱을 종료한 뒤 `%LOCALAPPDATA%\ipTIME-WOL\settings.json` 파일을 삭제합니다. 설정 파일을 버그 리포트에 첨부하지 마십시오.

## 버그 제보 시

공유기 모델, 정확한 펌웨어 버전, Windows 버전, 오류가 발생하는 단계와 **개인정보를 제거한** 오류 메시지만 공유하십시오. 실제 DDNS, 공인 IP, MAC, 관리자 ID/암호, 쿠키를 제공하지 마십시오.
